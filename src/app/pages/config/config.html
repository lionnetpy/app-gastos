Falta la configuración de Google

Para poder iniciar sesión, configurá tu proyecto en Google Cloud una sola vez y pegá tus credenciales en src/environments/environment.ts:

  1. Creá un proyecto en Google Cloud Console y habilitá Sheets API y Drive API.
  2. Creá un OAuth Client ID tipo "Web application" (orígenes: localhost:4200 y tu dominio Netlify).
  3. Creá una API Key y pegá ambos valores en environment.ts.
  4. En la pantalla de consentimiento: completá el correo de asistencia y agregá tu correo en Usuarios de prueba (si está en estado "En prueba"; si no, verás el error 403 access_denied).

Detalle completo en el README.md (sección "Configuración en Google Cloud").
