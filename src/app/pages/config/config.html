Falta la configuración de Firebase

Para poder iniciar sesión, creá tu proyecto gratuito en Firebase y pegá sus datos en src/environments/environment.ts:

  1. Entrá a console.firebase.google.com y creá un proyecto (plan gratuito Spark, sin tarjeta).
  2. Activa Authentication → Google y creá Firestore Database.
  3. En Configuración del proyecto → Tus apps → App web (</>), copiá los datos de configuración.
  4. Pegalos en environment.ts y publicá las reglas de seguridad del archivo firestore.rules.

Detalle completo en el README.md (sección "Configuración de Firebase").
